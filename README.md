# 커피 메뉴 관리 프로젝트

## 프로젝트 소개

데브코스 백엔드 10기 12회차 1차 프로젝트 6팀 육성입니다.

- [바로가기](https://nbe10-12-1-team6.vercel.app)

## 기술 스택

- Spring Boot
- Next.js
